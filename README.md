# Lab 1: Reproducible Computing Setup-Afrah Beshir

## What this is
A reproducible Python environment for computing a  summary statistics on patient ages, built with `uv`.

## Requirements
- Python 3.13+
- [uv](https://docs.astral.sh/uv/getting-started/installation/)

## Setup (get running in under 5 mins)
1. Clone this repo: git clone https://github.com/Amy123-hash/lab1-repro.git
cd lab1-repro

2. Install dependencies from the lockfile:
uv sync

3. Run the analysis:
uv run python src/analyze.py


## Expected output age
count 3.0
mean 54.0
std 7.0
min 47.0
25% 50.5
50% 54.0
75% 57.5
max 61.0


## Project structure

lab1-repro/
├── README.md
├── .gitignore
├── pyproject.toml
├── uv.lock
├── src/
│ └── analyze.py
├── data/
└── AI_USAGE.md
